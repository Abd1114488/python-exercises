GAME NAME  ROLLA

ABDULLAH 



A text game I made in Python. The well in your village is dirty and people are getting sick. You have to bring clean water back.

You walk around the village with commands like move, look and collect. You pick up or buy items, then go back to the village and type fix. You win when you have the right two items for one of three ways:

1.Engineer: filter part + pipes
2,Community: gloves + trash bag
3.Nature: seedling + spring water

You can also save your game and continue later.

The game is about clean water (Sustainable Development Goal 6). Each way to win is a way to protect water: technology, people working together, or nature.

To start the game, type python ROLLA.py in the project1 folder.

The code is split into a few files: ROLLA.py runs the game, and the game folder has the classes Item, Room and Player, plus the world, the actions and saving.
